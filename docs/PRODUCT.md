# Autrifix Web Product Context

The web application is one client of the Autrifix platform.

It should provide web experiences appropriate to the roles and workflows supported by the backend.

Potential web areas include:

- authentication;
- customer dashboard;
- service request creation;
- vehicle management;
- provider/service-provider dashboard;
- job management;
- messaging;
- notifications;
- ratings/reviews;
- administrative workflows where applicable.

The actual routes and implemented screens must be recovered from the current repository before being marked implemented.
